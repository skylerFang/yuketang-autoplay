# yuketang-autoplay
# 雨课堂目录连播助手

一个用于雨课堂学习页面的 Microsoft Edge 浏览器扩展，帮助减少手动切换视频的操作。

**当前版本：v0.5.0 测试版。** 尚未完成全面实测，不同课程页面可能需要进一步适配。

## 功能

- 当前视频播放结束后，尝试按左侧目录打开下一视频。
- 可选后台恢复：切换标签页导致暂停时，尝试恢复播放。
- 提供“测试下一节”按钮，立即检查目录切换。
- 设置面板默认收起，可拖动位置。
- 显示播放器检测结果及失败原因。

## 安装方法

适用于电脑上的 Microsoft Edge 浏览器。

1. 在本仓库首页点击 **Code → Download ZIP**，下载并解压。
2. 在 Edge 地址栏输入 `edge://extensions`，回车。
3. 开启 **开发人员模式**。
4. 点击 **加载解压缩的扩展**。
5. 选择包含 `manifest.json` 和 `content.js` 的文件夹。如果它们在子文件夹里，请选择该子文件夹。
6. 打开雨课堂视频页面，或刷新已经打开的课程页面。
7. 左下角出现 **连播设置** 按钮，即表示扩展已加载。

更新版本时，用新版文件替换原安装目录中的文件，在扩展管理页点击重新加载，然后刷新课程页面。不要同时启用多个版本。

## 使用方法

### 目录连播

1. 展开左侧需要连续播放的章节，并清空目录搜索条件。
2. 点击左下角的 **连播设置**。
3. 点击 **① 指定目录**。
4. 依次点击左侧当前视频和紧邻的下一视频，请直接点 **Video** 文字。
5. 点击 **② 开启连播**。

当前视频结束后，扩展会等待约 3 秒，再尝试打开下一项。

也可以点击 **测试下一节**，立即切换并检查是否正常播放。这个按钮会离开当前视频，请在准备好切换时使用。

### 后台播放

1. 手动开始播放视频。
2. 勾选 **切换标签页后继续播放**。
3. 保留课程标签页，切换到其他标签页。
4. 返回后检查播放进度及面板提示。

勾选开关只表示启用了恢复功能，不代表后台播放一定成功。浏览器或平台机制仍可能阻止恢复。

### 停止与收起

- **全部停止**：关闭连播与后台恢复，不会暂停当前视频。
- **收起**：隐藏设置面板，已开启的功能继续运行。
- 拖动小按钮或面板标题栏，可以调整位置。

## 已知限制

- 仅针对 `https://www.yuketang.cn/ai-workspace/lms-graph/` 下的页面。
- 目录连播依赖页面结构，尚不能保证所有课程都能正常切换。
- 只处理已识别到的视频目录，不会自动展开后续折叠章节。
- 手动切换课程、目录结构变化或切换超时后，可能需要重新指定目录。
- 如果切换视频触发整页刷新，需要重新开启功能。
- 跨域内嵌播放器暂不支持控制。
- 关闭课程标签页、离开课程网址或电脑休眠后，无法继续播放。
- 测验、确认弹窗等仍需要手动处理。
- 不修改学习进度数据，也不保证后台播放会计入学习进度；以平台显示为准。
- 已完成部分模拟逻辑检查，但不等同于真实课程中的完整验证。

## 隐私说明

扩展不设置外部数据接收服务器，不主动上传课程内容或账户信息。目录设置保存在当前标签页的会话存储中。

本项目是非官方学习辅助工具，与雨课堂及其运营方无关联。请根据所在学校和课程的要求使用。
